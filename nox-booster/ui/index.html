                Réglages

                Ping le plus bas possible sur Fortnite + booster la PlayStation de ton frère (réglages box)
                1. Nox Booster n'agit que sur ce PC. La PS5 se booste dans la box : ouvre son interface (192.168.1.1 ou 192.168.0.1) → QoS / Priorité → mets le PC et la PS5 en priorité « Jeu / Haute ».
                2. Sur la PS5 : IP fixe (bail DHCP statique dans la box) + UPnP activé ou ports Fortnite ouverts (UDP 5222, 5795-5847, TCP 5222, 5795-5847).
                3. Dans Fortnite : Région de matchmaking Europe fixée (pas Auto), « Statistiques réseau » activées pour vérifier. Le ping ne peut pas descendre sous la distance box → serveur Epic (≈ 15-25 ms en France).
                4. Sur ce PC (FPS) : Fortnite en Performance (mode rendu), V-Sync off, limite FPS = ton écran ou illimité, pilote GPU à jour, mode Faible latence NVIDIA Reflex activé.
                5. Câble : Cat 5e minimum branché directement à la box (pas de switch/CPL entre les deux), Wi-Fi désactivé sur le PC.

                Certains réglages (planification GPU, Nagle, timer) prennent effet après un redémarrage. Nox Booster ne peut pas améliorer la ligne de ton opérateur : il enlève ce que Windows met en travers.
